## اجرای همه تست‌ها

```bash
cd apps/backend && python -m pytest
```

```bash
cd apps/web && npm test && npm run typecheck && npm run lint && npm run build
```

با API و پنل در حال اجرا روی پایگاه داده توسعه (هر کدام جداگانه):

```bash
cd apps/web && for t in phase2 phase3 phase4 phase5 phase6 mobile-overflow; do E2E_USERNAME=coach E2E_PASSWORD='...' node e2e/$t.smoke.mjs; done
```

تست‌های زیرساخت (نیاز به root؛ فقط روی سرور آزمایشی یا محیط توسعه):

```bash
sudo infra/tests/test-nginx.sh
```

```bash
sudo infra/tests/test-compose-stack.sh
```

```bash
PGHOST=localhost PGUSER=basharnia PGPASSWORD='...' PGDATABASE=basharnia_dev STORAGE_PATH=./apps/backend/data infra/tests/test-backup-restore.sh
```
