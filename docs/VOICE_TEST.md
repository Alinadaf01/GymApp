# دوره تست ویس (بخش ۸.۴ سند)

هدف: سنجیدن دقت تبدیل گفتار و Parser روی **صدای واقعی مربی**، و اصلاح Parser و فرهنگ لغت بر اساس خطاهای واقعی.

## برای مربی: ضبط حدود ۲۰ ویس

1. در ربات `/start` را بزنید، یک شاگرد (واقعی یا آزمایشی) و نوع برنامه را انتخاب کنید و ویس بفرستید.
2. ویس‌ها را **همان‌طور که در کار روزمره حرف می‌زنید** ضبط کنید؛ لازم نیست شمرده یا رسمی صحبت کنید.
3. تنوع داشته باشید:
   - تمرینی: چند حرکت، ست و تکرار، تکرار هرمی (۱۲، ۱۰، ۸)، وزنه، استراحت، سوپرست و دراپ‌ست، حرکت‌های زمان‌دار (مثل پلانک یا دوچرخه).
   - چند ویس غذایی و چند ویس مکمل.
   - ویس‌های کوتاه و بلند (حتی تا ۲ تا ۳ دقیقه).
4. **مهم‌ترین بخش:** اگر نتیجه درست نبود، «✏️ اصلاح متنی» را بزنید و متن **درست و کامل** را بفرستید، بعد تأیید کنید. می‌توانید هم «🖥 بازبینی در پنل» را بزنید و در پنل اصلاح کنید. همین اصلاحات «جواب درست» برای سنجش دقت هستند.
5. در طول دوره تست، برنامه‌هایی را که فقط برای تست بودند می‌توانید بعداً در پنل بایگانی یا حذف کنید (پیش‌نویس‌ها قابل حذف‌اند).

## برای شما: گرفتن خروجی و ارسال

روی سرور:

```bash
cd /opt/basharnia && docker compose run --rm -T api python -m app.cli export-voice-eval > voice-eval.json
```

فایل `voice-eval.json` برای هر ویس شامل این موارد است: متن خام Whisper، اصلاح متنی مربی، خروجی Parser و برنامه‌ای که در نهایت ذخیره شد (بعد از اصلاحات پنل).

برای اینکه بتوانم مدل‌های دیگر Whisper (مثلاً `medium`) را روی **همین ویس‌ها** امتحان کنم، فایل‌های صوتی را هم بسته‌بندی کنید (ویس‌ها ۳۰ روز نگه داشته می‌شوند):

```bash
sudo tar -C /data/basharnia -czf voices.tar.gz audio && ls -lh voices.tar.gz voice-eval.json
```

برای دانلود به کامپیوتر خودتان، **روی کامپیوتر خودتان** اجرا کنید:

```bash
scp coachadmin@coach.example.com:/opt/basharnia/voice-eval.json coachadmin@coach.example.com:/opt/basharnia/voices.tar.gz .
```

سپس هر دو فایل را برای من بفرستید. این فایل‌ها نام شاگردان و برنامه‌ها را دارند؛ اگر نمی‌خواهید نام واقعی بفرستید، برای تست از شاگرد آزمایشی استفاده کنید.

## کاری که من با خروجی انجام می‌دهم

- محاسبه دقت: درصد حرکت‌هایی که نام، ست و تکرارشان درست تشخیص داده شد.
- شناسایی خطاهای پرتکرار Whisper (مثل «چار» به‌جای «چهار» یا نام حرکاتی که اشتباه نوشته می‌شوند) و افزودن آن‌ها به Parser و فرهنگ لغت.
- مقایسه مدل `small` با `medium` روی همین ویس‌ها، و سنجش اثر `WHISPER_VOCAB_HINT`.
- گزارش نتیجه و اعمال اصلاحات در یک به‌روزرسانی.
